:: TERMINAL_OPTIMIZATION

DEV_ENVIRONMENT_HACKS

2026-02-04 4 MIN READ PRODUCTIVITY

Seconds saved accumulate into hours. Optimizing your terminal environment is the highest ROI activity for any backend engineer.

KILL_PASSWORD_AUTH

Typing your password for every git push or server login is a waste of life. Use SSH keys. If you haven't set up key-based authentication yet, run this one-liner:

ssh-keygen -t ed25519 -C "your_email@example.com"

Then, copy it to your remote server instantly:

ssh-copy-id user@192.168.1.10

You will never type that server password again.

ALIAS_EVERYTHING

Your ~/.zshrc or ~/.bashrc is your personal toolbox. If you type a command more than twice a day, alias it.

  • alias gs="git status"
  • alias dc="docker-compose"
  • alias ..="cd .."
  • alias update="sudo apt update && sudo apt upgrade -y"
"The best developers are lazy. They automate everything."
