JWT_DISCIPLINE

2026-02-04 3 MIN READ CRITICAL PATCH

JWTs are powerful, but they are not magic. They are portable claims, and every claim is a potential vulnerability unless you validate it with intent.

FIELD_NOTE

Tighten validation first. Enforce issuer, audience, and expiration checks before adding new features or providers.

CLAIMS_WITH_INTENT

The most common JWT failures are not cryptographic. They are logical. Accepting the wrong issuer, skipping audience checks, or ignoring token expiration turns authentication into a best-effort guess.

Always treat the header and payload as untrusted input. The signature only guarantees integrity if you verify it correctly and enforce the rules you expect.

"Never trust a token you did not constrain."

DEFENSE_IN_DEPTH

Solid JWT handling is a stack of safeguards, not a single library call.

  • Validate iss, aud, and exp on every request.
  • Rotate signing keys and cache JWKS with a short TTL.
  • Use short-lived access tokens with refresh token rotation.

When JWTs are handled with discipline, they scale cleanly. When handled casually, they scale risk.
